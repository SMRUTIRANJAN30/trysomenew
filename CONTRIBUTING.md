# Contributing to trysomenew

We welcome community contributions, bug fixes, and feature proposals!

## Development Workflow

1. Fork and clone the repository.
2. Create a feature branch: `git checkout -b feature/my-new-tool`.
3. Install dependencies in `apps/web` (`npm install`).
4. Ensure all code compiles cleanly: `npm run build` and `npm run lint`.
5. Maintain the **No Fake Features** rule: all newly added tools must perform genuine processing.
6. Submit a pull request with detailed verification steps.
