# trysomenew web

The Next.js website behind [trysomenew.netlify.app](https://trysomenew.netlify.app). Setup and an overview are in the [main README](../../README.md).

| Path | Contents |
|---|---|
| `src/app` | Pages, one folder per tool |
| `src/components` | Shared interface parts |
| `src/lib` | PDF, hashing, search and SEO code |
| `src/lib/toolsData.ts` | List of tools |
| `tests` | Tests, run with `npm test` |
